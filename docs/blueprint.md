# **App Name**: EventFlow

## Core Features:

- Attendee Management: Allow attendees to register, unregister, and confirm participation, check status of registration, see invoice. Features include automated confirmations, waitlists, and session sign-ups.; possibility to create qr codes for attendees for easy registering at entrance; ability to register presence for attendees manually in case they do not have their qr code at hand
- Speaker Management: Enable speakers to register, submit proposals, upload and manage slides, administration of speaker status such as 'pending' 'confirmed' 'slides missing' etc. Includes tools for communication, feedback collection, and speaker profile management.
- Sponsor Management: Create and manage sponsor packages, including contact information, pricing of packages. Includes features for tracking sponsorship levels, benefits, and deliverables.
- Billing System: Manage different pricing tiers, early bird discounts, integration with external membership database, Stripe integration, refunds, and manual invoice creation. Supports various payment methods and automated invoicing.
- Export Data: Export data to xlsx format for reporting and analysis.
- Reporting: Generate reports including burn-up charts (how many participants are missing until the goal of XY is reached), track ticket sales over time, and analyze attendee demographics.
- Venue Management: Manage venue details, floor plans, and logistics information.
- Communication Tools: Built-in communication tools for sending announcements, updates, and reminders to attendees, speakers, and sponsors.
- Session Scheduling: Create and manage the event schedule, including sessions, workshops, and breaks. Allows for room assignments and speaker scheduling.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to evoke professionalism and innovation.
- Background color: Light grey (#ECEFF1), providing a clean, neutral backdrop.
- Accent color: Electric blue (#3D5AFE), used for interactive elements.
- Body and headline font: 'Inter', a sans-serif, for clear and modern readability.
- Use professional, consistent icons related to event management.
- Maintain a clean and organized layout for easy navigation.
- Subtle transitions and animations to enhance user experience.
